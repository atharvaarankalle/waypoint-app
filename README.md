# 📍 Waypoint > **Your schedule, mapped.**

Waypoint is a modern full-stack application that seamlessly blends smart meeting scheduling with AI-driven local discovery. It allows users to coordinate calendars and instantly receive tailored, location-aware suggestions on what to do, eat, or explore around their meeting spots.

## 🛠️ Tech Stack & Architecture

This project is managed as a clean, unified **Monorepo** to ensure synchronized feature delivery and consistent type safety.

- **Frontend:** Next.js (React, TypeScript, Tailwind CSS, Server Components)
- **Backend:** .NET 8 (C#)
- **Database & ORM:** PostgreSQL + Entity Framework (EF) Core
